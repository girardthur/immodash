---
description: Créer et appliquer les migrations Django
---

Crée et applique les migrations de base de données.

Exécute les commandes suivantes :
1. Crée les migrations : `python manage.py makemigrations`
2. Affiche le plan de migration : `python manage.py showmigrations`
3. Applique les migrations : `python manage.py migrate`
4. Vérifie qu'il n'y a pas d'erreurs
