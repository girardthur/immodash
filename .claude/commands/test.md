---
description: Lancer les tests Django avec coverage
---

Lance tous les tests de l'application avec coverage et affiche le rapport.

Exécute les commandes suivantes :
1. Lance les tests avec coverage : `coverage run --source='.' manage.py test`
2. Affiche le rapport de couverture : `coverage report`
3. Si des tests échouent, analyse les erreurs et propose des solutions
